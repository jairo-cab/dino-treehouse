# Style sheet — Dino Treehouse

**One look for everything.** Every image we generate must match this.

## The look (in one sentence)
Warm, soft storybook illustration for 7-year-olds: rounded chunky shapes, gentle shading, thin
soft dark-brown outline, big expressive eyes, bright but friendly colours.

## Rules
- **Shapes:** round and squishy. No sharp spikes, nothing scary. Big head, small body, tiny arms.
- **Outline:** thin, soft, dark brown (not black), same thickness everywhere.
- **Shading:** one soft shadow tone + one small highlight. No heavy gradients, no textures.
- **Eyes:** big, glossy, with a white highlight. They carry the emotion.
- **Light:** warm sunlight from the top-left.
- **Colours:** bright and clean. Dinos use ONLY the exam colours: black, blue, brown, green,
  orange, red, white, yellow (no pink or purple dinos!).
- **Backgrounds for characters/objects:** plain solid pure white, no floor, no shadow on the
  ground, nothing else in the picture. (We cut them out afterwards.)
- **No text, no letters, no logos** inside any image (words are added by the game).
- **Size:** square image, subject centred with a margin around it.

## Base style prompt (paste at the start of EVERY prompt)

> Soft children's storybook illustration style, for a 7-year-old English learning game.
> Rounded, chunky, squishy shapes. Thin soft dark-brown outline of constant thickness.
> Gentle cel shading with one soft shadow tone and one small highlight, no textures.
> Bright, clean, friendly colours. Warm sunlight from the top-left. Cute and never scary.
> Plain solid pure white background, no ground shadow, nothing else in the image.
> No text, no letters, no watermark. Square image, subject centred with margin.

## Workflow (important to keep the same character)
1. Use **one chat per character**. Generate the first picture (neutral) and pick the best one.
2. For the other expressions, **in the same chat** attach/keep that picture and say:
   *"Same character, same colours, same style, same size and pose. Only change the face to: …"*
3. Save every image you like in `assets/raw/` with the exact file name from the prompt list.
4. If the style drifts, paste the Base style prompt again and attach the first picture.
5. Gemini and ChatGPT free limits are daily: do the most important images first (marked ★).
